# Type: ChatShareThemeBackdrops

**Category**: Available types

**Description**: This object contains a list of backdrops, which can be used as the background of a theme of the screen for sharing a link to a user or a chat.

**Link**: [Official Documentation](https://core.telegram.org/bots/api#chatsharethemebackdrops)

### Fields

| Field | Type | Required | Description |
|---|---|---|---|
| backdrops | Array of ChatShareThemeBackdrop | Yes | The list of backdrops |

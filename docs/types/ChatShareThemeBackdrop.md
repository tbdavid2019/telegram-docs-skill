# Type: ChatShareThemeBackdrop

**Category**: Available types

**Description**: This object describes a backdrop, which can be used as the background of a theme of the screen for sharing a link to a user or a chat.

**Link**: [Official Documentation](https://core.telegram.org/bots/api#chatsharethemebackdrop)

### Fields

| Field | Type | Required | Description |
|---|---|---|---|
| id | Integer | Yes | Unique identifier of the backdrop |
| name | String | Yes | Name of the backdrop |
| colors | UniqueGiftBackdropColors | Yes | Colors of the backdrop |

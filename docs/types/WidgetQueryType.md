# Type: WidgetQueryType

**Category**: Available types

**Description**: This object describes the type of a query from a widget. Currently, it can be one of
- WidgetQueryTypeData
- WidgetQueryTypeSignData
- WidgetQueryTypeSentTransaction

**Link**: [Official Documentation](https://core.telegram.org/bots/api#widgetquerytype)

**Subtypes**: WidgetQueryTypeData, WidgetQueryTypeSignData, WidgetQueryTypeSentTransaction

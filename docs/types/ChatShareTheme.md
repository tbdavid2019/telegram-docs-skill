# Type: ChatShareTheme

**Category**: Available types

**Description**: This object describes the theme of the screen for sharing a link to a user or a chat. Currently, it can be one of
- ChatShareThemeEmoji
- ChatShareThemeUniqueGift

**Link**: [Official Documentation](https://core.telegram.org/bots/api#chatsharetheme)

**Subtypes**: ChatShareThemeEmoji, ChatShareThemeUniqueGift

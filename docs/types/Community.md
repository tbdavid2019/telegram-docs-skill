# Type: Community

**Category**: Available types

**Description**: Represents a community (a group of chats).

**Link**: [Official Documentation](https://core.telegram.org/bots/api#community)

### Fields

| Field | Type | Required | Description |
|---|---|---|---|
| id | Integer | Yes | Unique identifier for this community. This number may have more than 32 significant bits and some programming languages may have difficulty/silent defects in interpreting it. But it has at most 52 significant bits, so a signed 64-bit integer or double-precision float type are safe for storing this identifier. |
| name | String | Yes | Name of the community |

# Type: BotCommand

**Category**: Available types

**Description**: This object represents a bot command.

**Link**: [Official Documentation](https://core.telegram.org/bots/api#botcommand)

### Fields

| Field | Type | Required | Description |
|---|---|---|---|
| command | String | Yes | Text of the command; 1-32 characters. Can contain only lowercase English letters, digits and underscores. |
| description | String | Yes | Description of the command; 1-256 characters |
| is_ephemeral | Boolean | Optional | Optional. True, if the command sends an ephemeral message, which can be seen only by the sender of the message and the bot |

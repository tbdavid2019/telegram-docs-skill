# Method: getUniqueGift

**Category**: Available methods

**Description**: Use this method to get information about a unique gift by its name. Returns a UniqueGift object on success.

**Link**: [Official Documentation](https://core.telegram.org/bots/api#getuniquegift)

**Returns**: UniqueGift

### Parameters

| Field | Type | Required | Description |
|---|---|---|---|
| name | String | Yes | Unique name of the gift |
